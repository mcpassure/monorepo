# Code of Conduct

Este projeto adota o [Contributor Covenant](https://www.contributor-covenant.org/) versão 2.1.

## Nossa promessa

Nos comprometemos a fazer a participação neste projeto uma experiência livre de assédio para todos, independentemente de idade, tamanho corporal, deficiência, etnia, identidade de gênero, nível de experiência, nacionalidade, aparência, raça, religião ou identidade sexual.

## Comportamentos inaceitáveis

- Linguagem ou imagens sexualizadas
- Ataques pessoais ou políticos
- Assédio público ou privado
- Publicação de informações privadas de terceiros sem permissão

## Aplicação

Ocorrências de comportamento abusivo podem ser reportadas para: conduct@vetrum.com.br

Todas as reclamações serão revisadas e investigadas com confidencialidade.
